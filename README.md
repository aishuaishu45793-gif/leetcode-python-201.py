# Python Programming Practice

## About This Repository
This repository contains beginner-friendly Python programming practice projects. These programs help improve logical thinking, problem-solving skills, and understanding of basic Python concepts.

## Projects Included

| No. | Project Name | Description |
|---|---|---|
| 1 | Reverse a String | Reverses the given string using Python. |
| 2 | Sum of Digits | Calculates the sum of all digits in a number. |
| 3 | Prime Numbers in a List | Finds all prime numbers from a given list. |
| 4 | Common Elements in Two Lists | Finds the common values between two lists. |
| 5 | Simple Interest Calculator | Calculates simple interest using principal, rate, and time. |
| 6 | Character Counter | Counts the total number of characters in a string. |
| 7 | Largest Digit Finder | Finds the largest digit in a given number. |
| 8 | Remove Spaces from a String | Removes spaces from the entered string. |
| 9 | Power Calculator | Calculates the power of a number using a loop. |
| 10 | Strong Number Checker | Checks whether a number is a Strong Number using factorials of its digits. |

## Technologies Used
- Python

- Git

## How to Run the Programs

1. Clone this repository or download the project files.
2. Open the project folder in Visual Studio Code.
3. Open the terminal.
4. Navigate to the Python file location.
5. Run the program using:

```bash
python filename.py
```

Example:

```bash
python 205.py
```
